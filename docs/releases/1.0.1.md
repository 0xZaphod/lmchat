# LMChat 1.0.1

Fixes a crash when selecting a PDF document for attachment. PDF extraction now uses an Android-compatible library instead of desktop PDFBox, which required unavailable Java AWT classes.

Includes on-device regression tests for PDF extraction, plain-text and JSON files, invalid/empty documents, and sending a PDF with no accompanying message text.

## Installation

Download `LMChat-1.0.1.apk` and install it over the previous signed release. Android 8.0 or newer is required. Existing release installations keep their conversations and settings.

Debug/development installations signed with another key cannot update to this APK directly.
