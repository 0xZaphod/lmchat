# LMChat 1.0.2

AI replies now render Markdown while streaming:

- Headings, bold and italic text, and strikethrough.
- Ordered and unordered lists, blockquotes, and tables.
- Tappable links, inline code, and monospace code blocks.
- Selectable response text for copying.

Rendering runs off the UI thread, with paced updates during streaming. User messages remain plain text.

Verified with 18 unit tests and seven on-device tests, including Markdown formatting, incomplete streaming blocks, and updates inside the chat list. Includes the PDF attachment fix from 1.0.1.

## Installation

Download `LMChat-1.0.2.apk` and install it over the previous signed release. Android 8.0 or newer is required. Existing release installations keep their conversations and settings.

Debug/development installations signed with another key cannot update to this APK directly.
