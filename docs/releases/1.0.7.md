# LMChat 1.0.7

This update improves privacy defaults, attachment handling, and chat reliability. Updating from a previous official release is recommended.

- Android cloud backup is disabled, with explicit exclusions for app data in Android backup and device-transfer rules. Chats, attachments, API keys, and settings are intended to remain in the app's private storage. This change does not establish that historical backups have been erased. Uninstalling or clearing storage loses local data; chat export is not currently available.
- Added a [privacy statement](https://github.com/0xZaphod/lmchat/blob/v1.0.7/PRIVACY.md) covering server transmission, local storage, credentials, backup behavior, and GitHub update checks.
- Attachment imports now enforce limits before parsing: 10 MiB per image, 8 MiB per document, and at most 200 PDF pages. Extracted text is capped at 120,000 characters, with a truncation marker and clear rejection messages for oversized files.
- Fixed image downscaling for images just above the output-size limit.
- Replies in separate chats can be stopped independently. Duplicate sends are rejected, streams survive leaving the chat screen, and interrupted replies preserve saved partial text without overwriting existing error details.
- Database upgrades are tested from versions 1–3. Unsupported schema versions no longer trigger automatic deletion of chat history.

## Installation

Download `LMChat-1.0.7.apk` and install it over the previous official release. Android 8.0 or newer is required. The package uses version code 9 and the same signing certificate as 1.0.6. Existing chats and settings are retained when updating normally.

Debug/development installations signed with another key cannot update to the official APK directly.

## Validation

- 32 unit tests and debug/release builds passed.
- All 20 Android instrumentation tests passed on an Android 17 emulator. On the connected Pixel 7 Pro, 19 tests passed and the Markdown UI test could not complete while the device was locked; it passed in the emulator.
- Verified the signed 1.0.6 → 1.0.7 upgrade through Android's package-installer UI in the isolated emulator. Synthetic messages, a document attachment, selected model, and server settings were preserved.
- Verified the release APK signature with `apksigner` and matched its certificate to the previous public release.
