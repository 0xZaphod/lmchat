# LMChat 1.1

Android app for chatting with LM Studio, Ollama, llama.cpp, and other OpenAI-compatible servers.

- Stream replies and manage local conversation history.
- Attach documents, or images when the model reports vision support.
- Save servers, select models, and scan the local network.
- Connect using a host and port or a full HTTP(S) URL. Full URLs do not require a separate port.
- Display locally configured context limits without waiting for server metadata.
- Always-dark Material 3 interface.

## Installation

Download `LMChat-1.1.apk` below and open it on an Android 8.0+ device. Allow installation from your browser or file manager if prompted. A compatible model server must be reachable from the phone.

Existing release installations can update in place. Debug installations use a different signing key and may need to be uninstalled first, which removes their local data.
